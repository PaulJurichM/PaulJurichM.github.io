# malari.me

Главная страница сайта и привязка домена malari.me.

Остальные разделы живут в своих репозиториях и открываются по путям автоматически:
`/books/` — репозиторий books, `/hronotope/`, `/CloudAtlas/`, `/hp/` — хронотопы.
Новый репозиторий с включёнными Pages появится на malari.me/<имя-репозитория>/.

В проектных репозиториях не должно быть файла CNAME и своего Custom domain,
а ссылки внутри них должны быть относительными.
