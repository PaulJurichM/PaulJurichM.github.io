# malari.me

Личный сайт: обо мне, блог, работа, творчество.

- `src/about.md` — главная страница (в шапке `photo:` — путь к фото, например `/media/photo.jpg`; сам файл кладётся в `src/media/`).
- `src/blog/ГГГГ-ММ-ДД-адрес.md` — заметки блога. `draft: yes` в шапке прячет заметку.
- `src/work.md`, `src/work.json` — раздел «Работа».
- `src/work/адрес.md` — статья раздела «Работа» на странице `/work/адрес/`; в шапке `title`, `summary`, `tag`, `draft: yes` прячет. Помимо разметки блога понимает таблицы `| a | b |`, блоки ```, `### `, нумерованные списки и метку статуса строкой `@ текст`. Ссылку на статью добавить в `src/work.json`.
- `src/creative.md`, `src/creative/*.json` — «Творчество»: хронотопы, видео (id роликов YouTube), музыка (альбомы).
- `build.py` собирает всё в `docs/`; эту папку публикует GitHub Pages.

После коммита в `src/` GitHub Actions пересобирает сайт сам. Локально: `python3 build.py`.

Музыка: mp3 лежат в релизах этого репозитория, один релиз на альбом. Имя тега релиза = `tag` альбома в `src/creative/music.json`.

Остальные разделы живут в своих репозиториях и открываются по путям: `/books/` (проза), `/hronotope/`, `/CloudAtlas/`, `/hp/`, `/morse-encyclopedia/`, `/AiDriven/`, `/architect-study-plan/`.
В них не должно быть файла CNAME, а ссылки внутри должны быть относительными или от корня.
